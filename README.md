# Calculadora

Uma aplicação de calculadora funcional desenvolvida do zero como parte do currículo do **The Odin Project**.

**Acesse e teste a calculadora online:**  
[https://starfingar.github.io/calculator/](https://starfingar.github.io/calculator/)

---

## Como Usar

1. Acesse o link do projeto publicado.
2. Clique nos botões numéricos para formar o primeiro valor.
3. Escolha a operação matemática desejada (`+`, `-`, `×`, `÷`).
4. Digite o segundo valor.
5. Clique em `=` para ver o resultado final, ou em outro operador para dar sequência à conta.
6. Use o botão **`X`** para corrigir um dígito digitado incorretamente.
7. Use o botão **`C`** para reiniciar a calculadora a qualquer momento.
